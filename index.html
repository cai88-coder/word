    使用教程

    ① 播放列表怎么用
    1. 在「单词库」页点「＋ 新建列表」，起个名字，比如「展会英语」。
    2. 切到「全部单词」，勾选要加的单词 → 点「加入列表…」→ 选这个列表。
    3. 导入新单词时，在「同时加入」里选好列表，导入的单词会自动放进去。
    4. 要删减：在单词库上方切到这个列表，勾选单词 → 点「移出本列表」。单词仍保留在单词库里。
    5. 复习时，在「复习」页的「播放列表」里选它，就只播放这个列表里的单词。

    点开任意单词，在「所属播放列表」里也能直接加入或移出。

    ② 导出备份（iPhone）
    1. 点顶部提示条的「立即备份」，或打开底部「设置」页 →「导出单词库」。
    2. 弹出分享面板后，选「存储到文件」→「iCloud 云盘」，建议新建一个「单词备份」文件夹，点「存储」。
    3. 也可以在分享面板里选微信 →「文件传输助手」，在微信里留一份。
    4. 文件名带日期，例如「单词库备份_20261005.json」，保留最近几份就够了。

    备份包含全部单词、熟悉度和播放列表。电脑上点「导出单词库」，文件会下载到「下载」文件夹。

    ③ 恢复备份
    1. 打开底部「设置」页 →「导入备份」。
    2. 在文件选择里找到之前存的 .json 文件（iCloud 云盘 →「单词备份」）。
    3. 备份在微信里的话，先在微信打开文件 → 右上角「…」→「用其他应用打开」→「存储到文件」，再按上一步选择。
    4. 看到「已恢复 N 个单词」就完成了。同名单词以备份为准，库里其他单词保留不动。
    ⑤ 单词练习（遗忘曲线）
    1. 底部「练习」页显示今天该复习多少个词，红色数字角标提醒你还有多少没练。
    2. 每组 = 今天到期的复习词 + 若干新词（可选 5 / 10 / 20 个）。
    3. 题型随记忆阶段变难：先看英文选中文，再听音选词、看中文选英文，最后听音拼写。
    4. 每个词第一次作答决定进退：答对进一级，间隔按 1、2、4、7、15、30 天拉长；答错退两级，明天再出现。答错的词本组内还会再出，直到答对。
    5. 第 6 级再答对就算掌握，自动标为「熟悉」，复习页不再播放；答错的词会改回「陌生」，复习页会多读它。
    6. 每日任务：先在练习页点「🎧 先听一遍今天要复习的词」（或在复习页选「📅 今天到期的词」），听完再做练习。
    ⑥ 从文章里挑生词
    1. 「单词库」页 → 打开「📄 从文章里挑生词」，把客户邮件、产品手册等英文粘贴进去，点「挑出生词」。
    2. 默认跳过最常用的 5000 个词（按美国英语语料库词频）。觉得挑出来太多或太少，就调整「跳过常用词」。
    3. 人名、地名、品牌默认不勾选；其余生词勾选后点「加入单词库」，例句会用文章里的原句。
    4. 勾选「把含生词的原句也加入句库」，这些原句会进入句库的「文章摘句」场景，可以做句子练习。
    ⑦ 句子练习（工作场景句型）
    1. 「练习」页 → 句子练习 → 打开「管理句库」，点「载入示范句子」：展会介绍、报价谈判、交期付款物流、安装调试、售后培训、客户跟进，共 60 句。
    2. 也可以自己添加：每行一句，格式「英文 | 中文」，中文可以不填，再填一个场景名。
    3. 题型随记忆阶段变难：先听句子把单词排序，再看中文自己说英文，最后听写整句。排程同样按遗忘曲线。
    4. 复习页的「播放列表」里可以选「🗣 句子·场景」，开车、走路时直接听句子：英文读两遍，再读中文。
    ⑧ 一键加词（iPhone 快捷指令）
    1. 打开 iPhone 自带的「快捷指令」App → 右上角「＋」新建，名字改成「加入单词库」。
    2. 点底部的 ⓘ（详细信息）→ 打开「在共享表单中显示」。顶部出现「接收…输入」后，把「如果没有输入」改成「获取剪贴板」。
    3. 添加操作「URL 编码」，输入选「快捷指令输入」。
    4. 添加操作「URL」，内容填 https://cai88-coder.github.io/word/?add= ，在等号后面插入变量「URL 编码的文本」。
    5. 添加操作「打开 URL」，保存。
    6. 用法：在网页或邮件里选中单词 →「共享」→「加入单词库」；在微信里先「复制」，再点这个快捷指令（可以放到主屏幕）。一两个词会直接查词入库，一大段文字会自动进入「挑生词」。

    快捷指令会用 Safari 打开网页，所以单词会存进 Safari 里的单词库。请固定用 Safari 版本，不要和「添加到主屏幕」的版本混用。

    ④ 换手机 / 换浏览器迁移
    1. 在旧设备上导出一份最新备份。
    2. 在新设备上打开同一个网址。
    3. 「设置」页 →「导入备份」，选那份文件即可，熟悉度和播放列表都会保留。
