    使用教程

    ① 播放列表怎么用
    1. 在「单词库」页点「＋ 新建列表」，起个名字，比如「展会英语」。
    2. 切到「全部单词」，勾选要加的单词 → 点「加入列表…」→ 选这个列表。
    3. 导入新单词时，在「同时加入」里选好列表，导入的单词会自动放进去。
    4. 要删减：在单词库上方切到这个列表，勾选单词 → 点「移出本列表」。单词仍保留在单词库里。
    5. 复习时，在「复习」页的「播放列表」里选它，就只播放这个列表里的单词。

    点开任意单词，在「所属播放列表」里也能直接加入或移出。

    ② 导出备份（iPhone）
    1. 点顶部提示条的「立即备份」，或打开底部「设置」页 →「导出单词库」。
    2. 弹出分享面板后，选「存储到文件」→「iCloud 云盘」，建议新建一个「单词备份」文件夹，点「存储」。
    3. 也可以在分享面板里选微信 →「文件传输助手」，在微信里留一份。
    4. 文件名带日期，例如「单词库备份_20261005.json」，保留最近几份就够了。

    备份包含全部单词、熟悉度和播放列表。电脑上点「导出单词库」，文件会下载到「下载」文件夹。

    ③ 恢复备份
    1. 打开底部「设置」页 →「导入备份」。
    2. 在文件选择里找到之前存的 .json 文件（iCloud 云盘 →「单词备份」）。
    3. 备份在微信里的话，先在微信打开文件 → 右上角「…」→「用其他应用打开」→「存储到文件」，再按上一步选择。
    4. 看到「已恢复 N 个单词」就完成了。同名单词以备份为准，库里其他单词保留不动。
    ④ 换手机 / 换浏览器迁移
    1. 在旧设备上导出一份最新备份。
    2. 在新设备上打开同一个网址。
    3. 「设置」页 →「导入备份」，选那份文件即可，熟悉度和播放列表都会保留。
